Class Planning mode: How to use Cadance for free

Cadance 4 release — April 2026

Cadance's Free tier is called Class Planning mode — and it's a genuine product, not a crippled trial. You can browse, create playlists, and preview music without spending anything. Here's how to use it.

What you can do in Class Planning mode

Unlimited, no Day Pass required:

  • Browse the full Apple Music library (including DRM/cloud tracks)
  • Browse all 33 curated Cadance Resources playlists
  • Search and use "More Like This" discovery
  • Create, edit, rename, re-order, and import playlists
  • Import Apple Music playlists as editable Custom Playlists
  • Build playlist collages, organize folders, manage Favorites
  • Preview any track for 15 seconds (including Apple Music catalog tracks)
  • Use the metronome for 15 seconds per start
  • Browse from Apple Watch (15-second ceiling applies to playback)

What requires a Day Pass or subscription

Anything that crosses the 15-second mark:

  • Sustained track playback (past 15 seconds)
  • Sustained metronome (past 15 seconds)
  • Teaching Lock stays engaged (locks are tied to active playback)

The recommended Class Planning workflow

Here's how many teachers use Class Planning mode:

  1. Browse and discover: Search Apple Music or browse the curated Cadance Resources playlists.
  2. Preview: Listen to 15-second previews of tracks to evaluate them for your class.
  3. Create a custom playlist: Build a playlist for your class, adding tracks from any playable source — your local library files, file system files, cloud library files, and anything in the Apple Music library.
  4. Activate a Day Pass: When you're ready to teach, activate a Day Pass and play your class playlist.

Why this matters

Teachers can fully evaluate Cadance's tempo control and interface before paying anything. Studio admins and class planners who don't play music in class may never need to activate a Day Pass. Class prep at home or on the bus is genuinely free — you only pay on the days you actually teach.

For studio admins and planners

If you're a studio admin who plans classes but doesn't play music yourself, Class Planning mode is perfect for you. Create playlists, organize them by class, and hand them off to your instructors. No Day Pass needed.

Get started

Download Cadance 4 on the App Store and start exploring Class Planning mode. You'll also receive 14 free Day Passes to try full playback whenever you're ready.
